# Declaración de Uso de Inteligencia Artificial

## 1. IA Usada
* Gemini / ChatGPT

## 2. Modelo
* Gemini 1.5 Pro / GPT-4o

## 3. Prompts Realizados
* "Cómo crear la estructura base de un proyecto Vite con React y React Router."
* "Cómo realizar un formulario controlado en React con validación de estados mediante useState."
* "Diseño moderno con CSS para portafolio frontend en modo oscuro y glassmorphism."

## 4. Outputs
* Código base para componentes como `Layout`, `Header`, `Footer`, `TarjetaProyecto` y `FormularioContacto`.
* Guía paso a paso para comandos de Git y configuración del enrutador `react-router-dom`.

## 5. Ajustes Realizados
* Adaptación de nombres de variables y componentes al español de acuerdo con las instrucciones.
* Personalización de los textos reales sin usar 'lorem ipsum'.
* Corrección de errores en la terminal al crear carpetas y configurar las rutas.

## 6. Reflexión Crítica
El uso de la IA facilitó acelerar la estructuración de componentes y la resolución de errores sintácticos en la terminal. Sin embargo, fue fundamental comprender la lógica del flujo de datos en React (props, componentes controlados y rutas) para adaptar el código a las reglas requeridas por la evaluación.
